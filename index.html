YouTube Audio Delay Pro v2.4

Firefox Extension – Adjust audio delay for YouTube videos with precision

⬇ Install from Firefox Add-ons

🎵 Precise Adjustment NEW

Set audio delay with millisecond precision. Maximum delay is now 60,000 ms (60 seconds) for videos with severe audio desync.

🚀 Two Panel Types

Choose between Floating panel (inside video) or Inline panel (under video).

🎨 Adaptive Theme NEW

Inline panel supports Auto (follows YouTube), Light, or Dark themes. Options popup follows your Windows system theme.

How to Use

  1. Install the extension from the Firefox Add-ons Store
  2. Open any YouTube video
  3. Click the "OFF" button to switch to "ON"
  4. Adjust the delay using the +/-500 and +/-100 buttons
  5. Click on the delay value (e.g., "0ms") to type a custom delay directly
  6. Press "Reset" to set the delay back to 0
  7. Click the add-on icon in the Firefox toolbar to open Settings, where you can change panel type, theme, and default delay
